# Portfólio | Pablo Teodoro

Meu site pessoal, onde apresento quem sou e os projetos web e software que desenvolvi.

O diferencial é o visual de **terminal**: na página inicial, você navega digitando comandos como `help`, `ls` e `cd projetos`. Se preferir, também dá pra navegar normalmente clicando no menu.

## O que tem no site

- **Início**: o terminal interativo e meus projetos em destaque
- **Sobre**: minha apresentação, formação e habilidades
- **Projetos**: todos os meus projetos, com filtro entre web e software
- **Contato**: meus links e um formulário para me mandar mensagem

Todo o site está em **português e inglês**, com o botão `PT | EN` no menu.

## Tecnologias

Next.js, React, TypeScript e Tailwind CSS.

## Como rodar no seu computador

É preciso ter o [Node.js](https://nodejs.org) instalado.

```bash
git clone https://github.com/pabloteodoro/portfolio.git
cd portfolio
npm install
npm run dev
```

Depois abra [http://localhost:3000](http://localhost:3000) no navegador.
